## 🧩 About

**Knight Online overlay** is a curated list of Knight Online open-source tools:

- **Overlays** — on-screen helpers, layout notes, entity reader notes, minimap overlay sketches
- **Quality-of-Life Helpers** — inventory catalog, skill bar notes, loot tracking notes
- **Research Notes** — map layouts and config notes for educational use

Based on publicly available community tools and overlay helpers built for the Windows x64 client.

## ✨ Features

### 🎮 Combat Study Helpers
- Target Info Panel — read nearby entity stats for study
- Range Indicator — visualize spell and melee reach in the overlay
- Cooldown Tracker — display skill timers for practice rotations
- Damage Log Notes — record combat events for review

### 🗺️ Map & overlay Notes
- Minimap Overlay — draw a compact overlay of nearby points of interest
- Loot Tracker — catalog drops and node locations
- Waypoint Notes — mark farming routes and travel paths
- Zone Layout Sketches — annotate map segments for study

### 🎒 Inventory & QoL
- Inventory Catalog — browse items, stats, and weights
- Skill Bar Notes — organize hotkey layouts
- Config Profiles — save and load overlay presets
- HUD Customization — reposition panels for readability

### ⚙️ Overlay & Menu
- desktop helper — standalone window with tabs and toggles
- Hotkey Toggle — open with `Tab` or `Insert`
- Safe Mode — conservative defaults for stability
- x64 Build — tuned for modern Windows

## ⚙️ Configuration

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `menu_hotkey` | String | `"Tab"` | Toggle overlay |
| `process_name` | String | `"KnightOnLine.exe"` | Target process |
| `safe_mode` | Boolean | `true` | Keep conservative defaults |
| `overlay_scale` | Float | `1.0` | UI scale factor |
| `radar_radius` | Integer | `50` | overlay range in meters |
| `log_level` | String | `"info"` | Verbosity of notes |

## 🛠️ Troubleshooting

- **Overlay does not appear** — make sure the game runs in windowed or borderless mode.
- **Hotkey conflicts** — change `menu_hotkey` to another key such as `F8`.
- **Process not found** — verify `process_name` matches your client build.
- **Crash on launch** — enable `safe_mode` and disable extra panels.
- **Antivirus warning** — add the extracted folder to your exclusion list after review.
